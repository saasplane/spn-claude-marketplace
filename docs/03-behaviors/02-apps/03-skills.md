# Behaviors — Skills

`For: Backend developer · Web developer` · `Status: 🔮 PLANNING`

The table below lists the promises [Skills](../../02-constructs/02-apps/03-skills.md) makes. A row says what somebody can do and what they see when they do it.

Every row below is declared and none is claimed: a run writes the last two cells.

| Id | Who | Does | Sees | Type | Tier | Status | Updated at |
| --- | --- | --- | --- | --- | --- | --- | --- |
| MKT.SKILLS.08 | Backend developer | build a capability in an order that does not have to be undone | The contract step is read before the service, and each step before that layer's code | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.09 | Web developer | make a front-end change without walking the server steps | The ask is classified first, and the classification decides which steps apply | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.10 | Backend developer | reach a step written for this node's own language without naming one | The skill composes the step path from the stack the nearest manifest declares | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.11 | Backend developer | ask for a review and get the mode the ask meant | Each skill names its modes in the sentence a session matches against | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.12 | Backend developer | learn a mode is destructive before it runs | The reset mode is marked destructive in the description rather than only in the body | NEGATIVE | UNIT | PLANNED | — |
| MKT.SKILLS.13 | Architect | derive which standards apply from the skill that was invoked | Each skill declares the one stage it serves rather than mapping every skill to one | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.14 | Editor | be told when a skill has fallen behind the chapters it restates | Every skill carries a stamp, so a drift run reads a skill exactly as it reads a ref | NEGATIVE | UNIT | PLANNED | — |
| MKT.SKILLS.15 | Engineering leader | have a contract change reviewed by something that did not write it | The build skill closes with the suites and hands the change to the review skill | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.16 | Architect | decide what a node is without a second skill competing for the ask | That skill lives once in the core plugin, and this plugin supplies only the material it loads | NEGATIVE | UNIT | PLANNED | — |
