# Behaviors — Skills

`For: DevOps / SRE · Architect` · `Status: 🔮 PLANNING`

[Skills](../../02-constructs/03-infra/03-skills.md) makes the promises below. A row says what somebody can do and what they see when they do it.

Every row below is declared and none is claimed: a run writes the last two cells.

| Id | Who | Does | Sees | Type | Tier | Status | Updated at |
| --- | --- | --- | --- | --- | --- | --- | --- |
| MKT.SKILLS.17 | DevOps / SRE | change what the estate is and read it as one line per choice | The manifest is edited and validated, and the difference is shown in that shape | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.18 | Architect | send an authoring ask to the authoring skill rather than the declaring one | Each description names its neighbours, so a wrong ask lands in the right folder | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.19 | DevOps / SRE | read what a change would render before anybody approves it | The review states what a rendering must name and what it must never contain | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.20 | Architect | learn that a networked vendor is not a module before building one | The authoring skill rules the networked case out in the sentence a session matches against | NEGATIVE | UNIT | PLANNED | — |
| MKT.SKILLS.21 | DevOps / SRE | author a module from the first scaffold to the pin flip in one walk | One file covers scaffolding, rendering, proving, releasing and repointing the consumer | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.22 | DevOps / SRE | keep a package version in one place | The version is a reviewed edit to the package manifest, and the release command does the rest | POSITIVE | UNIT | PLANNED | — |
| MKT.SKILLS.23 | DevSecOps / Security | be sure no skill here changes a cloud on its own | Each skill names the tool's command that does, and restates the caution rather than working around it | NEGATIVE | UNIT | PLANNED | — |
| MKT.SKILLS.24 | Architect | read one walk whichever cloud the estate runs on | No skill here loads a per-cloud procedure, because the cloud does not change what an author writes | POSITIVE | UNIT | PLANNED | — |
