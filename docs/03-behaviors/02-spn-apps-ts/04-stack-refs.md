# Behaviors — Stack Refs

`For: Backend developer · Architect` · `Status: 🔮 PLANNING`

These are the promises [Stack Refs](../../02-constructs/02-spn-apps-ts/04-stack-refs.md) makes. A row says what somebody can do and what they see when they do it.

Every row below is declared and none is claimed: a run writes the last two cells.

| Id | Who | Does | Sees | Type | Tier | Status | Updated at |
| --- | --- | --- | --- | --- | --- | --- | --- |
| MKT.TSREF.01 | Architect | plan in this stack and still reach a concrete step | The general skill resolves the repository's claim and reads this stack's layer file | POSITIVE | UNIT | PLANNED | — |
| MKT.TSREF.02 | Backend developer | open the layer file directly and be told what it is | The file states in its first lines that it is reference material and not a skill | POSITIVE | UNIT | PLANNED | — |
| MKT.TSREF.03 | Architect | end a planning walk with rows in the documents rather than a scratch file | The file names the seats a row belongs in and marks each one planned | POSITIVE | UNIT | PLANNED | — |
| MKT.TSREF.04 | Engineering leader | tell which walk produced an output | The mode is taken from the skill's argument, and an inferred mode is named out loud | POSITIVE | UNIT | PLANNED | — |
| MKT.TSREF.05 | Editor | be told when this layer has fallen behind the chapters it restates | The file carries the same stamp a core restatement carries, and the drift run reads it | NEGATIVE | UNIT | PLANNED | — |
