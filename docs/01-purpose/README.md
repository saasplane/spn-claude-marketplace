# Purpose — spn-claude-marketplace

`For: Architect` · `Status: ✅ DONE`

**Why** — this seat answers why this repository exists — the problem it ends, the payoff of solving that once, what you get, and who it is for.

This seat is written for somebody deciding whether to build on this repository, and it carries no rules: normative language in a purpose seat is a defect.

| Page | Answers |
| --- | --- |
| [01-why](01-why.md) | why this repository exists — a rule a session cannot load reaches nobody, a partner is granted no book, and a standard held by review is one somebody has to remember |
| [02-what](02-what.md) | what installing it gives you — the plugins, the kinds of instrument inside them, and what this repository declines to be |
| [03-who](03-who.md) | who consumes it — the developers who meet these plugins through their agent, and `spnutils`, which installs and syncs them |

**The purpose set belongs to the repository**, so one of each page sits here and no plugin or folder carries its own. Everything more specific is a construct, a behaviour, a capability or a guide.
