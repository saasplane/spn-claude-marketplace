# Security policy — Claude Marketplace

If you have found a weakness in this repository, or in a package it publishes, please tell us
privately. We would rather hear about it from you than from anyone else.

## How to report it

Email **security@saasplane.ai**. Please do not open an issue, a pull request or a discussion,
because those are visible to others before a fix exists.

Tell us:

- what is affected: the package and its version, or the commit;
- how to reproduce it, step by step;
- what an attacker could do with it, as far as you can tell;
- how we can reach you, and the name you want credited, if any.

## What happens next

1. Within **2 business days** we confirm that your report arrived.
2. Within **5 business days** we tell you whether we could reproduce it, and the severity we gave it.
3. We fix it within the deadline for its severity, and tell you when the fix is released.
4. Once the fix is released, we credit you in its release notes, unless you would rather we did not.

| Severity | CVSS v4.0 score | Fixed within |
| --- | --- | --- |
| Critical | 9.0 – 10.0 | 7 days |
| High | 7.0 – 8.9 | 30 days |
| Medium | 4.0 – 6.9 | 90 days |
| Low | 0.1 – 3.9 | 180 days |

We rate severity with CVSS v4.0, and the deadline runs from the day we give it. If a fix will take
longer than its deadline, we tell you why, and the new date.

## Which versions are fixed

Only the latest release. A fix ships in a new release and is not applied to older ones, so update
to the latest release to receive it.

## What is in scope

The code in this repository and the packages it publishes. A platform built on these packages is
its owner's to secure; report a weakness in one to its owner.

## Research in good faith

We will not take legal action against research that follows this policy: it reports privately,
gives us the time above to fix, touches no one else's data, and stops at the proof that the weakness
exists.
