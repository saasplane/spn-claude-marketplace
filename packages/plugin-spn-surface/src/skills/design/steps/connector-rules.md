# Step: connector-rules — what a child agent needs to send `use_figma`

Read this step when you are an agent started by another and you are to send `use_figma` to change a component set. A child cannot read the connector's own skill resource, so these are the rules from it that a change of a set meets, in our words. The facts about how the connector behaves are in `refs/support/surface/delivery-library.md`, under "The connector's facts". Pass `skillNames: "resource:figma-use"` on each call; it is a name for logging, and it does not load the skill.

## The script

1. **Write plain JavaScript with top-level `await` and `return`.** Use no wrapper function and no `figma.closePlugin()`. `console.log` is not returned, and `figma.notify()` throws.
2. **Only the `return` value comes back.** Return every id made or changed, with counts and names: `return { createdNodeIds: [...], mutatedNodeIds: [...] }`. Keep that answer under the limit of rule 21: ids, counts and hashes, never a whole read. Nothing lives between calls, so pass an id from an earlier call into the script as text.
3. **Every call starts on the file's first page.** Switch with `await figma.setCurrentPageAsync(page)`, at most once in a call. `figma.currentPage = page` throws.
4. **Await every promise** (`getNodeByIdAsync`, `loadFontAsync`, `setCurrentPageAsync`).
5. **Load a text's fonts before any change near it.** Read the node's fonts with `getStyledTextSegments(['fontName'])`, call `await figma.loadFontAsync(...)` for each, then change it. This holds also for `appendChild`, `setBoundVariable` and a mode change on a node that holds text. Never guess a font style name: read `await figma.listAvailableFontsAsync()`.
6. **A colour runs from 0 to 1, and its paint's `color` holds `{r, g, b}` only.** Fills and strokes are read-only lists: copy, change the copy, assign it back. `setBoundVariableForPaint` returns a new paint, so keep it and assign it. An opacity set on a paint that is bound to a variable draws opaque, so the opacity goes on the layer.
7. **Sizing.** `layoutSizingHorizontal` and `layoutSizingVertical` take `FIXED`, `HUG` or `FILL` and are set on a child after it is appended to an auto layout parent. `primaryAxisSizingMode` and `counterAxisSizingMode` take `FIXED` or `AUTO` and are set on the frame. `resize()` resets the sizing to `FIXED`, so call it first.
8. **Read property definitions from the set, never from a version.** A version is a `COMPONENT` whose parent is a `COMPONENT_SET`, and it holds none. Check a node's `type` before you read a property that only some kinds have.

## The set

9. **A version's name is `property=value, property=value`.** A variant property exists because the versions' names carry it. Renaming `round=false` to `shape=SQUARE` in the name of every version renames the property and its value, and the versions keep their ids and keys.
10. **A new version is a copy of its nearest twin.** Copy with `twin.clone()`, set its `name`, `set.appendChild(copy)`, then place it by the set's grid and resize the set to hold it. The copy is a new component with a new key. A clone of a version inside a set turns each SLOT layer into a FRAME and drops the ties of its layers (seen on five sets, with ties dropped on text and on `visible`), so compare the copy with its twin and tie it again. The copy keeps the variable bindings, the text styles and the fill overrides of its layers (15 of 15 copies of a version), so bind nothing again.
    - **A slot is made again with the version's `createSlot()`, or as a copy of the twin's slot (rule 29).** The slot takes the frame's name, layout and children and its place among its siblings, and the frame is removed. Tie the slot with `componentPropertyReferences = { slotContentId: <the set's slot property key> }`. `createSlot()` also adds a new slot property to the set; once the slot is tied to the old key, remove the new one with `set.deleteComponentProperty(<the new key>)`.
11. **A set's default version is the one at its top left, not the first in its list of children.** Change the default by changing places in the grid, and read `set.defaultVariant.id` back after any move.
12. **A boolean or text property** is added with `set.addComponentProperty(name, 'BOOLEAN', false)`, which returns the key with its `#id` suffix. Tie a layer with `layer.componentPropertyReferences = { visible: key }` in every version. An instance takes values with `instance.setProperties({ 'prop': 'value' })`, and a boolean or text property needs the full key with its suffix.
    - **A text style covers font, size, line height, letter spacing, case and decoration.** Text layers of a set's versions that hold one style and are tied to one text property were seen to follow each other: a text property set on one was set on all. Before such a property is changed on one version, take the style off that layer and set its values on the layer. Figma's text decoration has no dashed value.
    - **A layer tied to a swap property is not swapped.** Swapping an instance that was tied to a swap property, inside one version, changed the default of that property for the whole set (seen once). Set the property's value instead.

## The call

13. **On an error, read `safeToRetryWithoutCanvasRead`.** If it is true, correct the script and send it again. If it is false, read the canvas first to see what changed, then go on. If the same API error comes twice, read the API's definition before a third try.
14. **Size a call so that it is safe to send again.** One set or one step to a call, a call under about 90 seconds, and about eight layers to a call on a set of hundreds of versions. Return evidence from each write (ids, counts, names, bounds), and take one picture after composing a set and one after a repair.
15. **Look before you make.** Read what the file holds and match its names and structure.
16. **Do only what your order names.** The permission check refuses a call that changes a library when the order did not name the change. A refused call is not sent another way: report it, and report what else you found.
17. **Work on one page at a time.** The connector refuses `figma.loadAllPagesAsync()` with "work on one page at a time". A script that needs the nodes of another page takes that page as an input (`pageId`) and switches to it once; to read several pages, send one call for each.
18. **Prove an answer that is copied to a file with a hash the script returns.** A script that reads a lot returns `rows` and `hash`, the FNV-1a hash of `JSON.stringify(rows)`. The agent saves each answer whole, exactly as returned, and runs `scripts/check-answers.mjs <folder>` over the folder, which finds a slip made while copying, a version missing from a unit and a gap between two answers of one page. It reads only answers that carry `rows` and a `hash` (`versions.js` and `instances.js`): over the answers of `inventory.js` it prints `0 answers, 0 pages, 0 failures` and proves nothing.
19. **A script that changes a library is dry by default.** It takes `dryRun: true` in its inputs, changes nothing under it and returns what it would do (counts, names, problems). Send it dry first, read the answer, then send it again with `dryRun: false`. `scripts/apply-spec.js` is one such script.
20. **A call made by `scripts/bundle.mjs` is passed whole and unchanged.** It holds one script's body and a list of runs, one for each set of a page, and answers `{ script, runs, of, stopped, answers }`, the answers in the order of the runs. Read every answer, not only the first. A run that is refused is that set's own, and the other runs are not held up; a run that threw ends the call, and its answer says `threw`. Every run of one call works on one page. The text you write into `code` must be the file's text exactly: the proof at the page's end is the hash of each set's versions.
21. **An answer over 20,480 bytes is refused, and the call's changes are not kept.** The refusal reads "Return value exceeds the 20480-byte limit" and says that the canvas edits of the run were not committed (seen once, on a read of 68,507 bytes). So a call that changes the file returns ids, counts and hashes and never a whole read. A large read is taken in parts, and a script that returns a long list takes a limit.
22. **The read that proves a change is a call of its own.** An answer read inside the call that made the change is no proof; send the read afterwards.
23. **A long script is passed whole, in a reply that holds that one call and no other text.** Nine sendings of long scripts broke off partway in two days: a call whose text ended in the middle of a statement was stopped by the safety check, and others ran their first lines and returned nothing. Before it sends the call, the agent knows the file's length (`wc -c`) and its last line, and checks that the text it passes ends there. The reply holds the call and nothing before or after it, and between two such calls the agent writes nothing but the next call. An answer that is "Interrupted", or "Code executed with no return value", or anything that is not the script's own answer, means the text broke off. A call that changes the file and is stopped is not sent again; a read-only script may be sent once more, whole, in a reply of its own, as `skills/design/steps/operations-and-composing.md` says for the scan.
    - **A long script goes through `bundle.mjs` with one run,** a file holding a list of one object: `node bundle.mjs --script <name.js> --inputs <file.json> --out <prefix>`. `bundle.mjs` leaves out every line that holds only a comment, wraps the script's body in a function that runs once for the entry, and replaces the page switch by a guard; the code is otherwise the script's own. The text is shorter, and the answer is `{ script, runs, of, stopped, answers }`, read from `answers[0]`. Measured with the tool on 2026-10-10: `scan-sets.js` is 29,207 characters, and the call `bundle.mjs` writes for it with one run is 20,303 characters. Measure the call of any other script with the tool, and do not take this number for it.

## The library

24. **A collection of another file's library is reached by an id that something in the file already carries.** Take it from the `explicitVariableModes` of a placed instance, on this page or on another, or from the variables a layer is bound to: `boundVariables`, then `figma.variables.getVariableByIdAsync`, its `variableCollectionId`, and `figma.variables.getVariableCollectionByIdAsync`, following alias values. Write both with `figma.variables.`: `figma.getVariableByIdAsync` does not exist, and a call to it throws. A mode is set with `instance.setExplicitVariableModeForCollection(collection, modeId)`, also on an instance that stands in the slot of another instance.
25. **`labels.js` refuses a set that has no label on either side.** The first labels of a set made new are written by hand, cloned from a neighbouring set's label.
26. **A mode set on a component is carried by every instance placed from it.** Set on the component a mode that every instance is to have. An explicit mode on an instance stops the mode of a frame above it: take it off with `instance.clearExplicitVariableModeForCollection(collection)` where the frame's mode is to reach the instance (each seen once).
27. **A component on another page of the file is placed from its id.** `await figma.getNodeByIdAsync(id)` returns it and `createInstance()` on it works while the current page is another, so switch no page and import nothing. A component of another library that the file does not yet use comes with `await figma.importComponentByKeyAsync(key)`, a variable with `figma.variables.importVariableByKeyAsync(key)` and a style with `figma.importStyleByKeyAsync(key)`. Read the key in the library's own file or in its inventory. There, `getPublishStatusAsync()` on a component answers `CURRENT` for a published one and `UNPUBLISHED` for one made since the last publish: draw with a published one until a person has published.
28. **A paint and a style are taken from a neighbour.** A paint read from one node and assigned to another keeps its variable binding, on `fills` and on `strokes`, also as `JSON.parse(JSON.stringify(node.fills))`, so bind nothing again. `setTextStyleIdAsync` and `setEffectStyleIdAsync` take a library style's id as the neighbouring layer carries it (`S:<key>,<node>`); for a text, load the style's font first.

## Slots and instances

29. **A slot at a new place keeps the property that `createSlot()` added.** `createSlot()` on a version adds one slot property to the set, and on a lone component to the component itself, and the new slot is tied to it at once. Name the slot layer, which names the property, delete nothing, and check that exactly one slot property was added. Delete the added property only where the slot replaces a frame that was tied to a slot property that stands (rule 10).
    - **A copy of a slot loses its ties.** `slot.clone()` put into another version of the same set stays a slot, keeps its layout, children and variable bindings and adds no property, and it loses `slotContentId` and `visible` (23 of 23 copies on one set, 4 of 4 on another). Tie each copy again in the same call: `copy.componentPropertyReferences = { slotContentId: <key>, visible: <key> }`.
    - **A slot carries two ties at once,** `visible` to a yes-or-no property and `slotContentId` to a slot property.
    - **Set `layoutMode` on a new slot before `strokesIncludedInLayout`.** The other order throws.
    - **A slot moved into another frame of its own version stays a slot.** After `appendChild` or `insertChild` it keeps its id and its ties, and the set's definitions stand.
30. **A node appended to the slot of an instance stands beside the slot's default content.** Remove the default content with `remove()` on that child. Build a frame whole, with its instances in it, before you append it to the slot. The appended node takes a new id that begins with `I`: read it back.
31. **A property ties to `visible` or to `characters`, and to nothing else.** A yes-or-no property shows or hides one layer; it changes no fill, no padding and no other layer, and the root of a version cannot be tied. Put what the property switches on a layer of its own (a rectangle, absolute at 0, 0 with both constraints `STRETCH`, that carries the root's fill, stroke and radius), and raise the root's padding by the weight of a stroke that counted in the layout. Set on the instance in the case what no property can change, and say so in the sheet's label.
32. **Read the overrides of placed instances before you change an instance inside a component.** A placed instance that overrode one variant property of the inner instance kept the inner instance's earlier version, and a text override on an inner instance whose version changed was dropped (each seen once). Set the overrides again afterwards.
33. **On a layer of an instance, take a binding off before you set a value.** `layer.setBoundVariable(field, null)`, then the value: a corner radius bound in the main component is made square this way, and a padding is freed. A swap set through a swap property keeps the fill set on an icon's vector, because every icon of Core names its vector `outline`.

## Text, places and layers

34. **Change a text in place, and set its layer's name yourself.** `insertCharacters` and `deleteCharacters`, from the last match to the first, keep the text's style, and text added at the end takes the font of the last character. A layer named by hand does not follow its text, so set a label's layer name in the same call.
    - **`fontName` takes a text style off.** Set it only where the layer is to hold no text style.
    - **Set `layoutSizingHorizontal` to `HUG` before `textAutoResize = "WIDTH_AND_HEIGHT"`** on a text that fills its auto layout frame, or it stays at `HEIGHT`.
    - **A text that hugs keeps the edge it is aligned to.** A right-aligned label keeps its right edge and a longer text moves its left edge; read `textAlignHorizontal`, set `x` again after the change, and check a longer label against the width of its section.
35. **Place a rotated layer by its `absoluteBoundingBox`.** Its `x` and `y` are the place of its own corner after the turn: an ellipse turned by 90 at `x` 0, `y` 0 has its box one diameter above. Set `x` and `y` by the difference of two `absoluteBoundingBox` readings.
36. **Do not trust a read of a hidden layer.** `findOne` on an instance did not return a hidden slot until the instance's yes-or-no property was set on. `children` of a hidden instance read empty on some versions and whole on others, so change the inside of a layer before it is hidden. A hidden child of an auto layout parent reads `layoutSizingHorizontal` as `FIXED` after it is set to `FILL`: compare `layoutAlign`.
37. **The layers panel reads from a parent's last child to its first.** `appendChild` or `insertChild` of a node into the parent it stands in changes its place in that order and nothing else. Order the layers by exact ids, appending from the last of the panel to the first, and check that no box changed. A search by type returns nodes in this order, so sort by id before you hash a proof.
38. **Rename by exact id.** A set, each of its versions and a lone component keep their ids and keys when renamed. An instance's layer that Figma named after its component takes the new name by itself; a layer named by hand keeps the old one, so rename it by its id. Read the id, the key and the versions back in a call of its own.
39. **Write a description back with plain apostrophes.** A set's `description` reads an apostrophe as `&#39;`, and a text written with `&#39;` reads back as `&amp;#39;` (seen on one set). Throw unless the description reads back as wanted.
40. **Prove a removal by the parent's children.** A removed component is still returned by `getNodeByIdAsync`, with no parent. `remove()` on a layer inside a set that is already removed throws `Removing this node is not allowed`.
41. **Prove a look by the bytes of its picture.** `await node.exportAsync({ format: "PNG" })` gives the same bytes for the same drawing. Hash them before and after a change that must leave a version's look as it stands, and return the hashes, never the bytes.
42. **`get_screenshot` gives the picture inline only with `enableBase64Response: true`.** Without the flag it answers with a link, and a shell that cannot resolve `www.figma.com` cannot fetch it. Pass a page's id for the whole page. A section 4,315 wide at `maxDimension` 3000 shows labels of 12 px; take the set at twice its own width to see a dashed edge of 1 px.
43. **An icon that Core lacks is made from its SVG.** `figma.createNodeFromSvg`, `outlineStroke()` on each shape, `figma.union` of the outlines and `figma.flatten` into the component give one filled vector. A shape that has a fill and a stroke goes into the union twice: the outline of its stroke, and the shape with its stroke taken off.
44. **Read a variant property's options back after the grid is laid out.** They read in the order of the grid's rows and not in the order the versions were combined in (seen once).
45. **Do not read `devStatus` of a section.** The read throws.
