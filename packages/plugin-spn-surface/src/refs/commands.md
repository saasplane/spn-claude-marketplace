# spn-surface commands

Generated by `node scripts/build-plugins.mjs` from the `commands/` tree. Never edited by hand.

spn-surface check module <module folder> — Refuse a folder of a web module that is outside its taxonomy: assets/ and entry/ only, folders by kind

spn-surface check page <spec.json> --app <app root> [--media <dir>] [--content <px>] — Refuse a page spec's raw colour, class on a unit, icon outside the app's set, wrong hero form, two emphases, misplaced or under-placed media

spn-surface check scan [<path>…] — Scan Surface code for every note the Surface check gives, whole files

spn-surface language write <app> [--construct <construct.md>] [--data <design-language.json>] — Fill a design-language construct's figures (drawing style, characters and building blocks, grounds, samples) from the app's design-language.json

spn-surface unit find <words…> [--repo <name or path>] [--json] — Name the units whose name or line carries a task's words, from the snapshot and the symbol index

spn-surface unit show <Unit> [--repo <name or path>] [--json] — Print one unit's props, values, defaults, usage and cases from the snapshot this plugin carries
