# Passes of FOUNDATION and GENERAL repositories

Read by table header, never by position. FOUNDATION: the book, then the docs checks once, then the release. GENERAL: plugin text restated from the book, then plugin source, then plugin tests, then the commit, the full run, the release and the install.

| Pass | World | Holds | Proof | After | Runs with | Waits on |
| --- | --- | --- | --- | --- | --- | --- |
| book | FOUNDATION | book | read back | — | — | — |
| docs-check | FOUNDATION | book | the docs checks, once | book | — | — |
| release | FOUNDATION | book | the release lands | docs-check | — | — |
| restates | GENERAL | book | plugin text regenerated by the build | — | — | — |
| source | GENERAL | source | the change reads back whole | restates | — | — |
| tests | GENERAL | tests | the cases are written, none run | source | — | — |
| commit | GENERAL | source | the commit by path | tests | — | — |
| full | GENERAL | source · tests | the full run, once | commit | — | — |
| release | GENERAL | source · tests | the release lands | full | — | — |
| install | GENERAL | source · tests | the plugin is installed | release | — | — |
