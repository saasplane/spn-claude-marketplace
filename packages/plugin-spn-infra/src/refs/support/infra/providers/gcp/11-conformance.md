**What to do instead.** Do not read an empty result as a pass. A provider with no rendering produces no run at all, and that is a different thing from a run that found nothing wrong. When a claim about this cloud has to be settled, the honest answer is that nothing has been exercised.

Those bind the day a first Google Cloud rendering exists.

**And one thing about this cloud is exercised on every declaration today.** The estate laws run Google's region and machine-type patterns at write time, so the refusal is live even though the rendering is not.

**So the gap is evidence, never criteria.**
